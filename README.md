# Drilling Billy — русская версия для Windows

**Drilling Billy**  — DOS-игра 1997 года от датской студии Northwind Soft (Роскилле). Билли роет ямы, заманивает в них чудищ и закапывает их. В игре пять миров: джунгли, стройка, подводный мир, пещеры и Египет.

Этот проект — любительский:
- **Русский перевод** игры: меню, подсказки, экран «Информация», кириллица в шрифтах;
- **Исправления**, чтобы игра работала в DOSBox-X без CD-привода, с музыкой и роликами;
- **Запуск для Windows**: игра открывается двойным щелчком, как обычная программа.

>  В этом репозитории лежат полная игра и DOSBox-X, всё готово к запуску.

## Установка

1. Скачайте репозиторий 

2. Запустить файл «Sound_setup.exe»:
	В Main Menu выберите **Select playback device** и нажмите Enter.
	В списке **Select Playback Device** выберите **Sound Blaster Pro/16/AWE32**, Enter.
	**Select Base I/O Port**: выберите **220**, Enter.
	**Select IRQ Interrupt Line**: выберите **IRQ 7**, Enter.
	**Select DMA Channel**: выберите **DMA 1**, Enter.
	**Select Sound Quality**: выберите **Very High Quality**, Enter.
	Выберите **Save and Exit** и нажмите Enter. 

3. Запускайте игру через «Billy.exe».

Ярлык на рабочий стол: правой кнопкой по `Billy` → **Отправить → Рабочий стол (создать ярлык)**.

## Структура
```
Billy.exe, Billy.bat, Sound_setup.bat, Reset_progress.bat, _find.cmd, billy.conf
dosbox-x\   ← портативный DOSBox-X
game\       ← игра: BILLY.EXE, DOS4GW.EXE, SETSOUND.EXE, CD\billy.cue + billy.bin, DB\, TEXT\, SETTINGS\, SAMPLES\ …
```

## Файлы запуска

| Файл | Назначение |
|---|---|
| `Billy.exe` | запуск игры |
| `Sound_setup.exe` | настройка звуковой карты |
| `Billy.bat` | игра на весь экран: 4:3, чёткая картинка, полосы по бокам |
| `Sound_setup.bat` | настройка звуковой карты (`SETSOUND`) |
| `Reset_progress.bat` | сброс прогресса (открытых карт) и рекордов |
| `billy.conf` | настройки DOSBox-X, можно править в Блокноте |
| `_find.cmd` | служебный: ищет `dosbox-x.exe` и проверяет, что игра на месте |

## Настройка

### Изображение
Игра работает в разрешении 800×600 (4:3). В `billy.conf` уже включены сохранение пропорций (`aspect = true`), чёткое масштабирование (`glshader = sharp`) и полноэкранный режим в разрешении монитора. **Alt+Enter** переключает полный экран и окно.

### Скорость
Если игра идёт слишком быстро или медленно, в `billy.conf`, в секции `[cpu]`, замените `cycles = auto` на число, например `cycles = 60000`.

### Настройки игры — `game\SETTINGS\OPTIONS.TXT`
```
sound: fx=100, cd=6;
misc: language=russian, speech=en, joystick=0, memory=8, playintro=1, cddrive=d;
screen: brightness=50, contrast=50;
```
| Параметр | Значение |
|---|---|
| `fx` / `cd` | громкость звуков (0–100) / музыки |
| `language` | язык текста: `russian` или `english` |
| `speech` | озвучка: `en` (английский) или `eo` (эсперанто) |
| `memory` | `8` или `16`: набор графики и звуков |
| `playintro` | `1` — показывать заставку |
| `cddrive` | буква CD-привода, игра выставляет её сама |

Пунктов «Текст» и «Речь» в меню игры нет, язык меняется только в этом файле.

### Сброс прогресса
Запустите `Reset_progress.bat` или удалите `game\SETTINGS\SAVEGAME` (прогресс) и `game\SETTINGS\HISCORE` (рекорды).

## Изменения по сравнению с оригиналом

### Русский перевод
- `TEXT\LANG.TXT`: добавлен язык `russian`, переведены все строки интерфейса.
- `TEXT\INFO.RU`: новый файл, перевод экрана «Информация».
- Кириллица нарисована в шрифтах `DB\MAINMENU.DB`, `DB\ALL8.DB`, `DB\ALL16.DB`, в двух цветах, в стиле оригинальных букв.
- Буква «я» записана кодом `0xF7` вместо `0xEF`: код `0xEF` игра считает надстрочным знаком.
- Добавлены невидимые символы-отступы `0xB0`, `0xB1`, `0xB2` (1, 4 и 8 пикселей) для ровных колонок: шрифт пропорциональный.
- Корректно выводятся названия языков, а латинские буквы в именах рекордсменов заменяются похожими русскими.

### Меню настроек
- Убраны пункты «Текст» и «Речь», язык задаётся в `OPTIONS.TXT`.

### Работа без CD-привода
- Если CD-привода нет, игра сама выполняет `IMGMOUNT D <диск>:\CD\BILLY.CUE -t cdrom` и находит привод заново.
- Если образ подключить не удалось, игра всё равно запускается, но без музыки и роликов.
- Проверка дорожки диска принимает и образы, где дорожка определяется как 0.

### Ролики
- Ролики проигрывает отдельная программа SMACKPLY (DOS-расширитель CauseWay). `BILLY.EXE` теперь сам добавляет в окружение `DOS16M=:10M`, без которого ролики не запускались.

### Без изменений
- Игровой процесс, уровни и концовка — оригинальные.

## Технические подробности

`BILLY.EXE` — программа Watcom C++ / DOS4GW (формат LE). Адреса — виртуальные адреса объекта 1.

| Место | Что сделано |
|---|---|
| MZ-заглушка, `IP=0x28A6` | 16-битный код: новый блок окружения с `DOS16M=:10M` |
| Объект 1 | виртуальный размер увеличен до `0x65000` под новый код (с `0x74600`) |
| `0x4D37E` → `0x74740` | замена латиницы на кириллицу при выводе символов |
| `0x50855`, `0x50A0F`, `0x50DFC`, `0x50F3D` | названия языков в меню |
| `0x4FDA9`, `0x4FE49`, `0x4FE8A`, `0x50121`, `0x50191`, `0x50B22` | меню настроек без «Текст» и «Речь» |
| `0x57BAC` → `0x74850` | режим без CD-привода |
| `0x580CA` → `0x7489C` | проверка дорожки: 14 или 0 |
| `0x57DF0` → `0x748C0` | автоподключение `CD\BILLY.CUE` через `IMGMOUNT` |

## Известные ограничения
- Русской озвучки нет.
- Финальный текст (`TEXT\ENDTXT.EN`) не переведён.
- Автоподключение образа работает только в DOSBox/DOSBox-X, буква `D:` должна быть свободна.
- Широкоэкранного режима нет: графика игры рассчитана на 800×600.
